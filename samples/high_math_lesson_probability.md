# 随机变量及其分布（高三数学）教案

## 一、教学目标
1. 理解随机变量的概念，会区分离散型与连续型随机变量。
2. 掌握离散型随机变量分布列的概念与性质，会求简单随机变量的分布列。
3. 理解二项分布、超几何分布与正态分布的模型特征及适用条件。
4. 能计算随机变量的期望与方差，体会概率统计在决策中的应用价值。

## 二、教学重点与难点
- 重点：分布列、二项分布、超几何分布、正态分布。
- 难点：区分二项分布与超几何分布的适用条件，正态分布的概率计算。

## 三、教学过程
### （一）情境导入
从"抛掷一枚骰子，朝上点数"这个随机试验引入，说明随机变量的取值由试验结果决定。

### （二）探究新知
1. 随机变量：对于随机试验样本空间 Ω 中的每个样本点 ω，都有唯一的实数 X(ω) 与之对应，称 X 为随机变量。
2. 分布列：设离散型随机变量 X 的可能取值为 x1,x2,…,xn，其概率 P(X=xi)=pi（i=1,2,…,n），则称表为 X 的分布列，满足 pi≥0 且 ∑pi=1。
3. 二项分布：在 n 重伯努利试验中，事件 A 发生次数 X 服从二项分布 X~B(n,p)，P(X=k)=C(n,k)·p^k·(1-p)^(n-k)。
4. 超几何分布：从含 M 件次品的 N 件产品中不放回抽取 n 件，次品数 X 服从超几何分布。
5. 正态分布：连续型随机变量 X 服从 N(μ,σ²)，其概率密度曲线关于 x=μ 对称，σ 越大曲线越"矮胖"。
6. 期望与方差：E(X)=∑xi·pi，D(X)=∑(xi-E(X))²·pi。

### （三）巩固练习
求掷两枚骰子点数和的分布列与期望；判断"有放回"与"不放回"抽样分别对应二项分布还是超几何分布。

### （四）课堂小结
分布列性质、二项分布与超几何分布的区别、正态分布特征、期望方差的含义。

## 四、板书设计
分布列：P(X=xi)=pi，pi≥0，∑pi=1
二项分布：X~B(n,p)，P(X=k)=C(n,k)·p^k·(1-p)^(n-k)
正态分布：X~N(μ,σ²)，关于 x=μ 对称

## 五、教学反思
二项分布与超几何分布是学生最易混淆的两个模型，应通过"有放回 vs 不放回"对比强化区分。
