# 椭圆及其标准方程（高二数学）教案

## 一、教学目标
1. 理解椭圆的定义，掌握椭圆标准方程的推导过程。
2. 掌握椭圆标准方程 x²/a² + y²/b² = 1（a>b>0）中 a、b、c 的几何意义及关系 a²=b²+c²。
3. 会求椭圆的焦点、离心率，能根据条件求椭圆标准方程。
4. 体会坐标法（解析几何）用代数方法研究几何问题的基本思想。

## 二、教学重点与难点
- 重点：椭圆定义与标准方程的推导。
- 难点：椭圆标准方程的化简，焦点在不同坐标轴时方程的区分。

## 三、教学过程
### （一）情境导入
用细绳两端固定两点（距离小于绳长）画出椭圆，引出椭圆的几何定义。

### （二）探究新知
1. 椭圆定义：平面内到两个定点 F1、F2 的距离之和等于常数 2a（2a>|F1F2|）的点的轨迹叫做椭圆，两定点叫做焦点。
2. 标准方程推导：以 F1F2 所在直线为 x 轴、中垂线为 y 轴建系，设 |F1F2|=2c，由定义 √((x+c)²+y²)+√((x-c)²+y²)=2a，化简得 x²/a² + y²/b² = 1，其中 b²=a²-c²。
3. 焦点在 y 轴时方程为 y²/a² + x²/b² = 1（a>b>0）。
4. 离心率 e=c/a（0<e<1），e 越接近 1 椭圆越扁，越接近 0 越接近圆。

### （三）巩固练习
已知椭圆焦点在 x 轴上，a=5，c=4，求标准方程；求椭圆 x²/9 + y²/4 = 1 的焦点坐标与离心率。

### （四）课堂小结
椭圆定义、标准方程两种形式、a²=b²+c² 关系、离心率几何意义。

## 四、板书设计
椭圆定义：|PF1|+|PF2|=2a（2a>2c）
标准方程：x²/a² + y²/b² = 1（a>b>0），a²=b²+c²
离心率：e=c/a，0<e<1

## 五、教学反思
标准方程的推导过程是解析几何"坐标法"思想的典型示范，应让学生经历"建系—设点—列式—化简"的完整过程。
