# 圆的周长（第一课时）教案

## 一、教学目标
1. 理解圆周长的含义，掌握圆周率 π 的近似值。
2. 掌握圆的周长计算公式 C = πd = 2πr，能正确计算圆的周长。
3. 经历测量、猜想、验证的探究过程，发展空间观念和推理意识。

## 二、教学重点与难点
- 重点：圆的周长计算公式的推导与应用。
- 难点：理解圆周率 π 的意义。

## 三、教学过程
### （一）情境导入
出示车轮、圆桌等圆形物体图片，提问："要知道圆桌边缘一圈有多长，该怎么办？"引出"圆的周长"概念。

### （二）探究新知
1. 实验测量：用滚动法和绕绳法测量圆形纸片的周长与直径，记录数据。
2. 发现规律：计算周长与直径的比值，发现都接近 3.14。
3. 认识圆周率：介绍 π 的意义，以及祖冲之对圆周率研究的贡献。
4. 归纳公式：C = πd = 2πr。

### （三）巩固练习
已知直径或半径求周长，以及已知周长求直径的逆向练习。

### （四）课堂小结
回顾公式，强调 π 取近似值 3.14 时的计算规范。

## 四、板书设计
圆的周长
C = πd = 2πr
π ≈ 3.14

## 五、教学反思
通过动手测量让学生亲历"猜想—验证"的过程，理解圆周率的本质，而非死记公式。
