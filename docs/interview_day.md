> 全程约 5 分钟，账单约 ¥3。

| 项 | 选什么 |

## 2. 配安全组（1 分钟，最容易忘）

控制台 → 安全组 → 入方向规则，**只开两个端口**：

| 端口 | 用途 | 来源 |
|---|---|---|
| 8000 | Web 演示 | `0.0.0.0/0` |
| 22 | SSH（排查用） | 你的 IP 或临时 `0.0.0.0/0` |

⚠️ **5433 / 19531 / 30000 绝对不开**（PG/Milvus/Attu 无鉴权，裸奔会被扫）。

---

## 3. 验证服务就绪（2~3 分钟）

实例开机后，**等 1~2 分钟让模型预热**（开机自启链路：Docker → PG/Milvus → teachmate → 预热），然后：

```bash
curl -s http://<公网IP>:8000/health
# 期望 {"status":"ok"}
```

浏览器打开 `http://<公网IP>:8000/`，用 `teacher01 / Teacher@123456` 登录，页面正常出来即就绪。

如果 health 不通，SSH 上去看：

```bash
ssh root@<公网IP>
docker ps                      # 5 个容器都要 Up
systemctl status teachmate --no-pager | head -15   # active (running)
journalctl -u teachmate -n 50  # 看有没有报错
```

## 4. 演示路径（核心，建议按这个顺序）

### 教师端（teacher01）

1. **AI 助手**（首页）：问「圆的周长公式怎么推导？」，展示流式回答 + 知识库检索来源。
2. **智能备课**：科目数学、年级六年级、主题「圆的周长与面积」→ 生成教案，展示 10 节点进度 → 「✓ 满意保存」→ 我的教案列表出现。
3. **学情报告**：选六年级4班、数学 → 生成报告，展示掌握度分布 / 学生分层 / 典型错题 / 教学建议 → 底部「批量备课」一键跳备课（体现 seam 联动）。
4. **试卷批改**：教师端看「已发布」列表（按准确率标红绿）+ 待复核。
5. **布置作业**：选有学生的班级（六年级4班）→ 选题布置。

### 学生端（切 student01，体现角色差异）

1. **我的作业**：查看作业 → 作答提交。
2. **试卷批改**：用「使用样例答卷」提交 → 查看批改结果 + 教师评语 + 薄弱点。

### 演示要点（口播）

- 强调**多 Agent 架构**：4 个独立 Agent（答疑/备课/学情/批改）+ 统一入口 orchestrator。
- 强调 **RAG**：AI 助手回答带来源、备课检索知识库/教材。
- 强调 **Human-in-the-Loop**：备课教师可提意见回炉、试卷教师复核后发布。
- 强调**数据真实性**：30 学生分层数据、真实批改对错矩阵，不是空壳。

## 5. 常见坑速查

| 现象 | 解法 |
|---|---|
| health 不通 | 等 2 分钟（模型预热）；`docker ps` 看容器；`journalctl -u teachmate -n 50` 看报错 |
| 页面空白 / 无流式 | 浏览器 **Ctrl+F5** 强刷（清缓存）；确认带宽 ≥10M |
| 端口 8000 连不上 | 安全组没开 8000，回第 2 步 |
| 生成慢 / 被 kill | 内存不足，SSH 加 swap：`fallocate -l 8G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile` |
| 时间显示不对 | 不会发生（已修时区，后端 +0800 + 前端 fmtTime） |
